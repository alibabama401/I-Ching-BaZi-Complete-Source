产品功能与玩法流程

四柱八字

时间校准

公开范围与使用边界

请按实际文件评估。 当前仓库公开的是一个浏览器端演示、若干 Java 服务接口和产品截图，并非截图所示系统的完整可构建后端。根页面中的节气、纳音和大运逻辑含简化或占位实现，不应直接用于专业判断。正式开发应补充依赖、领域模型、实现类、历法规则和自动化测试。

常见问题

可以直接运行什么？

下载仓库后可在浏览器打开根目录 index.html 查看前端演示。Java 文件为接口片段，缺少完整工程依赖时不能单独构建。

截图中的功能都已开源吗？

截图证明产品界面和功能场景，不等同于所有算法实现都在公开仓库中。请以源码目录和交付清单为准。
